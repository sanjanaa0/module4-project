Project Overview

This project is a full-stack Product Management application built using Django REST Framework, React, and PostgreSQL.

It provides a REST API and a React-based user interface to create, view, update, and delete products.

The project is containerized using Docker and Docker Compose and deployed to the cloud using Render.

Main Objectives

-Build a Django REST API
-Create a React frontend
-Integrate PostgreSQL database
-Dockerize the application
-Configure NGINX and Gunicorn
-Deploy the application to Render
-Test CRUD operations in production
